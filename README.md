# Gateway Malawi

Website for Gateway Malawi, published with GitHub Pages at https://timbo-1.github.io/Gateway/.

## Pages

- `index.html` – start page with the two business cards
- `about.html` – about section, reached via the tab at the top
- `imprint.html`, `privacy.html` – legal pages (fill in the highlighted fields)
- `contact/*.vcf` – contact files behind the "Save contact" buttons

## Editing

Colours and the font are set at the top of `style.css`.
The font (Inter) is hosted in `fonts/`, so no data goes to Google.
